# HorasJogadas 3.3.1 — rolagem apenas com o cursor

Removido o círculo fixo que aparecia no ponto do clique ao ativar a rolagem automática. Agora apenas o cursor do mouse indica a direção.

O funcionamento continua igual: clique na roda e mova para cima ou para baixo para controlar a velocidade. Outro clique ou **Esc** encerra. Também é possível segurar a roda, mover e soltar para parar.

Atualize em Configurações → Verificar atualizações ou use os arquivos abaixo. Registros e cronômetros permanecem preservados. Windows: instalador ou ZIP portátil. Linux x86_64: `HorasJogadas-Linux-x86_64.tar.gz`. Não precisa instalar Python. Confira `SHA256SUMS.txt`.
